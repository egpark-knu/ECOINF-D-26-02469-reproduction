# Data Availability Statement

The authors declare that all data and code supporting the findings of this study are available in a public repository to ensure full reproducibility.

The derived analysis-ready datasets and the exact Python scripts used for statistical modeling and satellite index extraction have been deposited at:
[https://github.com/egpark-knu/ECOINF-D-26-02469-reproduction]

Due to third-party distribution terms (e.g., KOGL restrictions for K-water datasets) and excessive volume, the raw bulk API downloads are not redistributed directly. However, the exact scripts provided in the repository include explicit URLs and programmatic logic to re-acquire and process these raw datasets from their official government and Earth Engine endpoints.

The machine-readable versions of the article's tables and figure statistics are in the `tables/` directory of the repository: `table2_synthesis.csv`, `figure2_group_statistics.csv`, `figure3_correlation_statistics.csv`, and `table_mask_variant_uncertainty.csv`.
